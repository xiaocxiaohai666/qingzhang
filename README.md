# 青账 · 微信账单助手

一个无需安装依赖的本地记账网页。直接导入微信个人对账 XLSX 或 CSV 后，自动分类、去重，并展示月度收支和交易明细。

「交易对象」图表将同一对象的交易金额累加，按金额从大到小、从左到右显示柱状图。每根柱子显示金额、次数和日期范围，点击后可查看交易日、首笔与最近一次交易时间，并进入该对象的逐笔明细。支持支出、收入、退款和全部交易，按所选月份更新；可搜索对象、显示前 10 / 20 个或分页查看全部对象。图表只统计参与金额汇总的交易，「全部交易」将金额相加，不做收支抵消。

## 使用

直接用 Microsoft Edge 或 Chrome 打开此目录的 `index.html`。点击「体验示例」可以先查看虚构账单；示例不会写入真实账本。

1. 在微信中找到「我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单」，选择「用于个人对账」。入口可能随版本变化。
2. 如果导出的是 ZIP，先解压，找到 XLSX 或 CSV 文件；收到 XLSX 文件时可以直接导入，无需转成 CSV。
3. 点击「导入微信账单」，选择一个或多个 XLSX / CSV，检查预览中的新增数、重复数和无法识别的行，再确认导入。
4. 点击交易分类或「详情」修正分类。可以记住交易对象的分类，应用于之后导入的记录。
5. 在「数据管理」中定期导出 JSON 备份。恢复备份时合并交易，保留已有手动分类。

所有文件都在浏览器本机处理。网页没有服务器、账号、远程字体、外部脚本、AI 接口或遥测。它不会直接读取微信，也不自动抓取邮件或支付通知。

## 保存和统计

- 账本和分类规则存储于当前浏览器的 `localStorage`，键名为 `qingzhang.wechat-ledger.v1`。使用同一浏览器和同一打开方式；更换浏览器或网址、无痕模式、清理浏览器数据可能导致看不到历史账本。浏览器本地存储不等同于加密存储。
- CSV 明细导出只包含当前月份和筛选条件下的记录。完整迁移和恢复手动分类请使用 JSON 备份。
- **支出按原始付款金额汇总，包含已退款的原单；独立退款单独列出，不计入收入，也不从支出扣减。** 不根据原单的退款状态推算退款金额，以避免与独立退款记录重复计算。因此汇总不是净消费，也不是账户余额。
- 零钱充值、提现、零钱通转入转出、信用卡还款等自动标为账户转移；普通向他人转账按账单收支方向保留。分类为「账户转移」「不计入」、无收支方向、失败、关闭、取消和待完成的交易不参与金额汇总。
- 重复导入优先匹配微信交易单号，没有单号时匹配时间、金额、对象、商品等完整字段。重复交易会更新原始字段，保留手动分类。
- 金额使用整数分计算，不使用浮点数累加。自动分类采用本地关键词和你保存的交易对象规则，可以人工修正。
- 支持 UTF-8、GB18030 和带 BOM 的 UTF-16 CSV。支持账单前的说明行、逗号、双引号、跨行商品描述和较长交易单号。单文件最大 20 MB、10 万行。
- 支持 XLSX 工作簿，自动查找账单工作表、识别 Excel 日期和数字金额；跨 XLSX / CSV 导入共享去重和分类规则。解析库随项目本地加载，断网也可使用。加密的 Excel 文件需先在 Excel / WPS 中用密码打开，另存为不带打开密码的 XLSX。

- 当前不支持旧版 XLS、PDF、压缩包直接导入或个人微信实时自动同步。

## 开发与检查

不需要构建。界面为 `index.html` + `styles.css` + `app.js`，共享账单处理逻辑为 `ledger-core.js`，Excel 读取入口为 `xlsx-import.js`，本地解析库在 `vendor/`。

安装了 Node.js 的环境可以运行：

```powershell
node --test tests/ledger-core.test.js tests/xlsx-import.test.js tests/counterparties.test.js tests/browser.test.js
```

`samples/wechat-demo.xlsx` 和 `samples/wechat-demo.csv` 是同一份虚构的测试账单，可用于尝试导入、重复导入和分类修改。与「体验示例」不同，手动导入此文件会将其加入你的真实本机账本；仅用于测试，请勿混入自己的账单。
