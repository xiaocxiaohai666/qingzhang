关于导入和统计

怎么获得微信账单？

通常在微信「我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单」，选择「用于个人对账」。导出文件如果是 ZIP，请先解压，再导入其中的 XLSX 或 CSV。收到 XLSX 文件时可以直接导入，无需转换。不同版本的入口可能有所变化。

青账如何统计？

支出按照账单中的原始付款金额汇总，已退款的原单仍保留在支出中。退款交易单独归类，不计入收入。「独立退款」只汇总独立退款记录，不从支出中扣减，也不会根据原单状态推算退款。月度数字是账单汇总，并非净消费或账户余额。

零钱充值、提现、零钱通转入转出、信用卡还款等被标记为账户转移；失败、关闭、取消和待完成的交易不参与金额汇总。普通向他人转账按账单收支记录，你可以自行修改分类。

重复导入会怎样？

优先根据微信交易单号去重；没有单号时，根据交易时间、金额、对象等字段匹配。已有记录更新账单字段，保留你手动修改的分类。同一商户不一定对应同一种消费，自动分类结果可以随时修正。

数据保存在哪里？

保存在当前浏览器的本地存储中。更换浏览器、换一种打开地址、使用无痕模式或清除浏览器数据，都可能让你看不到原来的账本。请定期通过「数据管理」导出 JSON 备份，备份可以恢复分类和规则。

当前版本支持个人对账 XLSX 和 CSV。加密的 Excel 文件需先用密码打开，另存为不带打开密码的 XLSX。不直接连接微信，也不支持 PDF、旧版 XLS 或自动读取邮件。
